🎯 5 Authoring Modes

Preflight gates route tasks directly to specialized execution modes:

  • Mode 1: Capture-driven (mitmproxy on port 12138)
  • Mode 2: Reference existing case
  • Mode 3: Manual cURL
  • Mode 4: Java Controller source / Jacoco coverage
  • Mode 5: API-TPL driven generation

⚡ Quick Start

Run tests or start the local traffic capture proxy:

# Run full test suite
python -m pytest tests/ -v

# Start capture proxy (Port 12138)
.\capture\start.bat

# Verify capture status
python tools/check_capture_server.py

🛡️ Key Architecture

Engineered to minimize LLM context hallucinations:

  • Preflight Gates: Mandate insertion anchors before code changes.
  • SQLite API Index: Replaces expensive recursive greps with sub-millisecond lookups.
  • Pytest Closure: Automated iteration on test failures until green.
